Cakupan

Empat modul, satu envelope

Setiap respons memakai amplop JSON yang sama: { success, data, timestamp }. Konsisten untuk recon, scan, analisis web, maupun utilitas.

◈

Recon

/api/v1/recon
  • GET /dns Resolusi A/AAAA/CNAME/MX/NS/TXT
  • GET /subdomain Enum subdomain: brute + passive (crt.sh)
  • GET /whois WHOIS terstruktur + raw opsional
  • GET /reverse-ip Reverse DNS (PTR)
  • GET /email-security SPF/DKIM/DMARC/DNSSEC + grade
  • GET /takeover Deteksi subdomain takeover
  • GET /profile Profil recon domain agregat
  • GET /ip GeoIP + ASN + reverse
  • GET /wayback URL historis (web.archive.org)
⊹

Scan

/api/v1/scan
  • POST /ports TCP scan konkuren + banner grab
  • GET /banner Ambil banner satu host:port
  • — Label service umum (ssh, http, mysql…)
  • — Spec port fleksibel: 22,80,8000-8100
◭

Web

/api/v1/web
  • GET /headers Audit security header + grade A–F
  • GET /tech Fingerprint teknologi web
  • GET /tls Inspeksi sertifikat & cipher TLS
  • GET /surface robots/sitemap/security.txt, metode, CORS
  • POST /probe Batch liveness + favicon hash (mmh3)
⊞

Util

/api/v1/util
  • POST /hash MD5/SHA1/SHA256/SHA512/CRC32
  • POST /hash-identify Tebak jenis hash
  • POST /encode base64 · base32 · hex · url
  • POST /jwt-decode Bongkar JWT (tanpa verifikasi)

Aman secara default

API publik, tanpa auth — tetap dijaga

Karena terbuka tanpa autentikasi, proteksi bergeser ke lapisan lain: pembatasan laju, penolakan target internal, dan validasi input di setiap parameter.

SSRF Guard default ON

Menolak target private, loopback, link-local, dan endpoint metadata cloud 169.254.169.254. Cegah penyalahgunaan untuk menyisir jaringan internal.

Rate Limit per-IP

Token-bucket per alamat IP dengan eviction otomatis. Balas 429 saat burst habis, plus header Retry-After.

Batas & Validasi enforced

Cap jumlah port, ukuran body, dan panjang banner. Domain/host/URL/IP divalidasi sebelum menyentuh jaringan.

⚠

Hanya untuk pengujian yang diizinkan. Tool ini melakukan reconnaissance aktif terhadap target yang Anda tentukan. Gunakan hanya pada sistem yang Anda miliki atau memiliki izin tertulis eksplisit untuk diuji. Tanggung jawab penggunaan ada pada Anda.

Mulai

Jalankan dalam 30 detik

Butuh Go 1.26+. Konfigurasi lewat environment variable — default sudah aman untuk deployment publik.

# clone & jalankan
$ go mod download
$ go run .              # listen :8080

# atau via Makefile
$ make run
$ make test             # unit test hijau
$ make build            # -> bin/pubapi

# atau Docker (multi-stage, distroless)
$ make docker
$ docker run -p 8080:8080 pubapi-offsec

# coba endpoint pertama
$ curl "localhost:8080/api/v1/recon/dns?domain=example.com"
